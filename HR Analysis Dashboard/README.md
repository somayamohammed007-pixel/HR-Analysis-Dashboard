# 📊 HR Analysis Dashboard

## 📌 Project Overview
This project presents an interactive HR Analytics Dashboard built using Microsoft Excel, Power Query, and Power Pivot.

The dashboard helps analyze employee retention, attrition, overtime behavior, salary distribution, and work-life balance to support HR decision-making.

---

## 🛠️ Tools & Techniques
- Microsoft Excel
- Power Query
- Power Pivot
- Data Cleaning
- Data Modeling
- Pivot Tables & Pivot Charts
- Interactive Dashboard Design

---

## 📊 Dashboard Pages

### Page 1
- Retention by Education Field
- Retention by Overtime
- Retained by Department
- Average Monthly Income by Job Level
- Work-Life Balance by Job Role

### Page 2
- Attrition by Job Role
- Attrition by Department
- Attrition by Overtime
- Overtime by Education & Gender

---

## Project Workflow
1. Cleaned and transformed HR data using Power Query
2. Built relationships and data models using Power Pivot
3. Created KPIs and pivot-based analysis
4. Designed an interactive dashboard in Excel

---

## 🚀 Final Outcome
The dashboard provides valuable HR insights into employee behavior, retention patterns, overtime impact, and attrition trends, enabling data-driven workforce analysis.
